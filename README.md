# knu-schedule-to-calendar
Chrome extension to sync KNU schedule with Google Calendar.

Chrome-розширення для автоматичного імпорту розкладу занять із системи АСУ КНУ (asu.knu.edu.ua) у ваш особистий Google Calendar.

Можливості розширення:
- зчитує розклад безпосередньо з відповідної вебсторінки АСУ КНУ;
- створює події в вашому особистому Goggle Calendar з точним часом, назвою дисципліни, аудиторією або посиланням на онлайн-заняття (за наявності).

Як використовувати:

ВАЖЛИВО: розширення поки що працює в тестовому режимі, розповсюджується у вигляді вихідного коду і доступне виключно для тестувальників. Якщо ви хочете використовувати його як тестувальник, зв'яжіться зі мною.

Для встановлення розширення вручну в режимі розробника виконайте наступні дії:
1. Завантажте цей репозиторій як ZIP-архів (кнопка Code ➔ Download ZIP) або клонуйте його на комп'ютер.
2. Розпакуйте архів у зручну для вас папку.
3. Відкрийте браузер Google Chrome і перейдіть за адресою: chrome://extensions/
4. У верхньому правому куті увімкніть перемикач «Режим розробника» (Developer mode).
5. У лівому верхньому куті натисніть кнопку «Завантажити розпаковане» (Load unpacked) і виберіть папку з розширенням. 

Після встановлення:
1. Перейдіть за адресою https://asu.knu.edu.ua/
2. Авторизуйтесь в АСУ ЗВО  і відкрийте розклад (власний, або обраної групи/студента/викладача). За необхідності налаштуйте діапазон дат, що будуть відображатись.
3. Викличте розширення KNU Schedule to Calendar з панелі Розширень (Extensions) в Chrome.
4. Натисність на кнопку "Додати в календар". Може знадобитись авторизація в Календарі та підтвердження, що ви довіряєте розширенню.
5. Перевірте Google Calendar. Ваш розклад тепер там.

Використані технології:
- JavaScript (ES6+) - логіка роботи розширення та парсинг DOM.
- Chrome Extensions API (chrome.identity, chrome.scripting, chrome.tabs) - авторизація через профіль браузера та взаємодія зі сторінкою.
- Google Calendar REST API - створення подій у календарі користувача.
